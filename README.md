# Piecesurv

Piecesurv is a Web3 project centered around a custom crypto token called **Gomu**. This project allows users to interact with Gomu tokens in various ways, including claiming tokens, checking balances, and transferring tokens between accounts. The backend of this project is built using Motoko, reflecting the growing potential of decentralized applications.

## Features

- **💰 Claim Gomu Tokens**  
  Users can claim **10,000 Gomu** tokens once to get started.
  
- **📊 Check Account Balances**  
  Users can easily view their Gomu token balances.
  
- **🔄 Transfer Gomu Tokens**  
  Gomu tokens can be transferred between accounts seamlessly.

## Technology Stack

- **Motoko**: The backend is built using Motoko, a programming language designed for creating smart contracts and decentralized applications on the Internet Computer.

## Getting Started

To get started with Piecesurv, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/yourusername/piecesurv.git
   cd piecesurv
   ```

2. **Install dependencies**:
   Make sure you have the necessary dependencies installed to work with Motoko.

3. **Deploy the backend**:
   Use the Motoko environment to deploy the backend on the Internet Computer.

4. **Interact with Gomu tokens**:
   Start by claiming your 10,000 Gomu tokens and explore the other features.
